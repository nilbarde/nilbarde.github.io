# MBA Application Materials — Documentation Index

This folder holds all source material for Nihal's MBA applications. The corpus is split into four subfolders by purpose: **canonical story modules**, **shared reference & frameworks**, **school-specific drafts**, and **unprocessed new material**.

If you're new to this corpus, the fastest mental model is:

1. **Truth lives in `stories/`.** Numbered `.md` modules, one per topic, each self-contained.
2. **`common/` is for things that apply across stories** (frameworks, quick metrics lookup, evolution notes).
3. **`<SCHOOL>_<YEAR>/` folders hold drafts written for a specific application.** They are downstream of `stories/`.
4. **`new_work/` is the staging area** — anything captured in a chat or written ad-hoc lands here first. The goal is to integrate useful pieces back into `stories/` and archive the raw file.

See `ORGANIZATION.md` for the full structure and the integration pipeline.

## Maintenance Notes

- `new_work/` raw sources are **archived** into `new_work/_archive/` once integrated. They are not deleted, so they remain available as historical reference.
- When a `stories/` file is edited materially, update `00_INDEX.md` if the change affects metrics, length, or essay-fit.
- Files in `LBS_2025/` are historical — they should not be edited. Future school folders (`HEC_2026/`, `INSEAD_2026/`, etc.) follow the same `<SCHOOL>_<YEAR>/` pattern and should include a `prompts.md` capturing the school's verbatim prompt text.
- The legacy story-file format uses ALL-CAPS section headers rather than `#` markdown headings. This is consistent across all files and works fine for the actual purpose (raw material for essays). Full markdown-lint compliance is a separate cleanup item if ever desired; not blocking.
